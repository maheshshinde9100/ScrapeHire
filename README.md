# ScrapeHire

ScrapeHire is a web-based job dashboard that aggregates job listings from publicly available sources using Python web scraping and APIs.

## Features
- View latest job listings in a clean dashboard  
- Filter jobs by category or company  
- Real-time updates from scraper-friendly sources  
- SEO-friendly job pages for better visibility  
- Backend APIs for easy data access and integration  

## Tech Stack
- **Frontend:** Next.js (JavaScript), React, Tailwind CSS  
- **Backend:** FastAPI (Python), Uvicorn  
- **Web Scraping:** Requests, BeautifulSoup, Public Job APIs  
- **Database:** PostgreSQL (planned)
